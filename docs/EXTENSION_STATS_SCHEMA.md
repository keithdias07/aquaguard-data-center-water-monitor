# Extension statistics export format (schema v1)

Produced by **Settings → Export statistics** in the extension (`exportStats()` in `extension/src/shared/settings.js`) and read by the dashboard (`src/extension_analytics.py`). Statistics are only recorded if you turn them on (off by default).

**The file never contains prompt text, page URLs or page content.** Unknown fields are dropped on import.

```jsonc
{
  "schema": "aquaguard.prompt-optimizer.stats",   // required, exact
  "schemaVersion": 1,                              // required
  "exportedAt": "2026-10-17T12:00:00.000Z",
  "extensionVersion": "0.1.0",
  "tokenizer": { "id": "heuristic-bpe-v1", "exact": false },  // counts are ESTIMATES
  "firstRecordedOn": "2026-10-01",                 // local date, no time
  "containsPromptText": false,
  "totals": {
    "optimizationRuns": 0,       // analyses (after typing pauses or manual clicks)
    "runsWithSuggestion": 0,
    "runsUnchanged": 0,          // analyses where no safe optimization was found
    "latencyMsTotal": 0,         // sum of compression latency over runs
    "promptsCompleted": 0,       // prompts sent or cleared after at least one analysis
    "promptsOptimized": 0,       // ...with an applied (not undone) optimization
    "promptsLeftUnchanged": 0,   // ...where no safe optimization existed
    "promptsDeclined": 0,        // ...where a suggestion existed but was not applied
    "applyActions": 0,
    "autoApplied": 0,
    "undoActions": 0,
    "originalTokensApplied": 0,  // estimated tokens before Apply
    "optimizedTokensApplied": 0, // estimated tokens after Apply
    "tokensSaved": 0,            // estimated, at the moment Apply was clicked
    "tokensSavedUndone": 0,
    "reductionPctSum": 0         // sum of per-apply reduction %, for the average
  },
  "summary": {                   // derived, for convenience (recomputed on import)
    "promptsOptimized": 0, "promptsLeftUnchanged": 0, "promptsDeclined": 0,
    "netTokensSaved": 0, "averageReductionPct": 0, "averageLatencyMs": 0,
    "optimizationRuns": 0, "applyActions": 0, "undoActions": 0, "appliedNet": 0
  },
  "daily": [
    { "date": "2026-10-01", "optimizationRuns": 0, "runsUnchanged": 0, "promptsOptimized": 0,
      "promptsLeftUnchanged": 0, "promptsDeclined": 0, "tokensSaved": 0, "tokensSavedUndone": 0 }
  ],
  "transformations": { "greeting": 0, "verbose-phrase": 0 }   // rule id -> applied count
}
```

## Derived metrics

| Metric | Formula |
|---|---|
| Net estimated tokens saved | `max(0, tokensSaved − tokensSavedUndone)` |
| Average reduction | `reductionPctSum / applyActions` (0 if no applies) |
| Average latency | `latencyMsTotal / optimizationRuns` (0 if no runs) |
| Per-apply reduction | `100 × (original − optimized) / original` (0 if original is 0) |

## Files in `data/extension/`

| File | Content | In Git? |
|---|---|---|
| `extension_stats_sample.json` | **Synthetic** sample (`"sampleData": true`), generated by `npm run sample-stats` | yes |
| `extension_stats.json` | Your own export, if you place it here | **no** (git-ignored) |
| `prompt_eval_results.json` | Evaluation aggregates and per-prompt metrics, no prompt text (`npm run eval`) | yes |
