    Privacy & permissions

    • Local processing. Prompts are optimized inside your browser. The extension makes no network requests.
    • Only the prompt box. It reads the prompt field on the listed sites, nothing else on the page, and nothing on other sites.
    • No prompt storage. Your original text is kept in memory only, for Undo, and is discarded when the tab closes.
    • Permissions: storage (save these settings) and access to the four chat sites listed above (to read and, when you click Apply, replace the prompt box).
    • The website you type into still receives whatever prompt you send. AquaGuard does not change that.
